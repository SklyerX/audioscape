## Getting started with AudioScape

Navigate to your [dashboard](/dashboard), if you don't already have an account create one by visiting the [auth portal](/auth)

After that click on the button shown in the image below.\

![Create Key](/docs/dashboard.png)

Then fill out the information as shown below.

*optionally you can set a Webhook URL to get notified when a track you queued has finished analysis.*

![Create key modal](/docs/create-key.png)

Then copy the key and webhook secret shown in the dialog.

![Copy secrets](/docs/copy-key.png)

> !! THIS INFORMATION WILL NOT BE SHOWN TO YOU EVER AGAIN AFTER CLOSING THIS MODAL, PLEASE ENSURE YOU HAVE COPIED IT !!

Thats all!

Make your first API request! Check out [search](/docs/API/search) for more information on how to do that.

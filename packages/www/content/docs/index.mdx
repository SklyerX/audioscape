>  Audioscape is a collection of curated audio-features, accessible to everyone. Works just by making one API call. Open Source, Open Code.

## Introduction

This is **not** a service made for high-level usage. The models that extract the audio features were pre-trained by [University Pompeu Fabra](https://mtg.github.io/essentia.js/)

The core part of this API uses Essentia.js for the extractions and these models and samples (extracted from YouTube) are not as strong as other platforms such as [Sound Charts](https://soundcharts.com/en/audio-features-api)

If you are using this in a serious, production, company platform, you may want to enhance the models yourself or use a different platform.

This was made for the average person looking to get their hands on a free and open-source tool for their side-projects that doesn't annoy them. Like if you're building a project for a music recommendation system, a stats page, etc.

## Why I built this

I felt like this would be a fun challenge and project to work on. I've been meaning to make something like this for a bit. I've been playing with Essentia for a while now and it always annoyed me how complicated some of the features were so I decided to make this project as a learning experience and a way to make the average-user suffer less when trying to get audio features

When [Spotify](https://developer.spotify.com) removed their audio features it was hurtful to us indie devs, for a while there was no other solution that was free, however with the power of technology now a lot of competitors have risen up to take that throne. They're only issue? You gotta sell a kidney to be able to use their API
